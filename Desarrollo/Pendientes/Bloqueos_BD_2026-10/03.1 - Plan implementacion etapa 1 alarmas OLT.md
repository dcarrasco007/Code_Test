# 03.1 — Plan de implementación etapa 1 · Alarmas OLT

Volver a [[00 - Indice Bloqueos BD]] · Diseño y diagnóstico: [[03 - bhaul-dev OLT_ALARMAS_CRITICAL]]

## Objetivo

Que el proceso de alarmas OLT use **una sola conexión** a la BD y haga **una sola carga** (`DELETE` + INSERT multi-fila en una transacción) con los datos de todas las OLTs, en vez de ~150 conexiones con INSERT fila a fila y `TRUNCATE`.

## Resumen del diseño

1. El padre lanza los ~150 hijos con `nohup timeout 450 php … &`.
2. Los hijos hacen ping + telnet y escriben un `.json`. **No se conectan a la BD.**
3. El padre espera 3 min y revisa; si faltan OLTs, revisa cada 1 min hasta los 8 min.
4. A los 8 min (o antes, si llegan todas) carga lo que haya en una transacción.
5. El monitoreo (`MONITOREO_PROCESOS_EJECUCIONES`) queda **comentado**, no se borra.

## Parámetros

Definirlos como constantes al inicio del padre, para ajustarlos sin tocar la lógica.

| Constante | Valor | Para qué |
|---|---|---|
| `TIMEOUT_HIJO` | `450` s (7,5 min) | `timeout` de cada `nohup`. Debe ser **menor** que la espera máxima del padre. |
| `ESPERA_INICIAL` | `180` s (3 min) | Primera espera después de lanzar el último hijo. |
| `INTERVALO` | `60` s (1 min) | Espera entre revisiones. |
| `MAX_CICLOS` | `5` | Revisiones extra después de la inicial → 3 + 5 = **8 min máximo**. |
| `TAM_BLOQUE` | `1000` filas | Tamaño de cada INSERT multi-fila dentro de la transacción. |
| `DIR_LOTES` | `/var/www/procesos/php/Alarmas_PHP8/tmp` | Carpeta donde se crea `lote_<id>/`. |

> Por confirmar: si el máximo es 8 min en total (`MAX_CICLOS = 5`) o 3 + 8 ciclos (`MAX_CICLOS = 8`, 11 min). En los dos casos `TIMEOUT_HIJO` tiene que ser menor que la espera total.

- [ ] **2.4** Comentar los 5 `TRUNCATE TABLE`.
- [ ] **2.5** Leer `OLT_SERVER` a un arreglo y **cerrar la conexión** antes de lanzar hijos:
  ```php
  $olts = $mysqli->query("SELECT ip, server, region FROM OLT_SERVER")->fetch_all(MYSQLI_NUM);
  $mysqli->close();
  ```
- [ ] **2.6** Crear la carpeta del lote:
  ```php
  $dir = DIR_LOTES . "/lote_$lote_id";
  mkdir($dir, 0775, true);
  ```
- [ ] **2.7** Lanzar los hijos con `timeout 450` y la carpeta como 5º argumento:
  ```php
  foreach ($olts as [$ip, $server, $region]) {
      $region = str_replace(' ', '_', $region);
      shell_exec("nohup timeout " . TIMEOUT_HIJO . " php -f $hijo $ip $server $region $lote_id $dir"
               . " > $logs/$server.log 2>&1 &");
  }
  ```
- [ ] **2.8** Ciclo de espera y revisión:
  ```php
  $esperados = count($olts);
  sleep(ESPERA_INICIAL);
  for ($ciclo = 0; $ciclo <= MAX_CICLOS; $ciclo++) {
      $listos = count(glob("$dir/*.json"));
      echo date('H:i:s') . " revisión $ciclo: $listos/$esperados\n";
      if ($listos >= $esperados) break;
      if ($ciclo < MAX_CICLOS) sleep(INTERVALO);
  }
  ```
- [ ] **2.9** Anotar en el log las OLTs que faltaron:
  ```php
  $llegaron = array_map(fn($f) => basename($f, '.json'), glob("$dir/*.json"));
  $faltan   = array_diff(array_column($olts, 1), $llegaron);
  if ($faltan) echo "Sin respuesta (" . count($faltan) . "): " . implode(', ', $faltan) . "\n";
  ```
- [ ] **2.10** Juntar los resultados:
  ```php
  $filas = ['CRITICAL' => [], 'MAJOR' => [], 'MINOR' => [], 'WARNING' => []];
  $cantidades = [];
  foreach (glob("$dir/*.json") as $archivo) {
      $r = json_decode(file_get_contents($archivo), true);
      foreach ($r['alarmas'] as $sev => $lista) array_push($filas[$sev], ...$lista);
      $cantidades[] = $r['cantidad'];
  }
  ```
- [ ] **2.11** Agregar la función `insertar_lote()`:
  ```php
  function insertar_lote(mysqli $db, string $tabla, string $cols, array $filas): void
  {
      foreach (array_chunk($filas, TAM_BLOQUE) as $chunk) {
          $n    = count($chunk[0]);
          $fila = '(' . implode(',', array_fill(0, $n, '?')) . ')';
          $stmt = $db->prepare("INSERT INTO $tabla $cols VALUES " . implode(',', array_fill(0, count($chunk), $fila)));
          $stmt->bind_param(str_repeat('s', $n * count($chunk)), ...array_merge(...$chunk));
          $stmt->execute();
          $stmt->close();
      }
  }
  ```
- [ ] **2.12** Carga en **una conexión y una transacción**:
  ```php
  $db = new mysqli($host144_geret, $user144_geret, $pass144_geret, 'Aden');
  $cargado = false;
  try {
      $db->set_charset('utf8');
      $db->query('SET SESSION lock_wait_timeout = 10');
      $db->begin_transaction();

      $tablas = ['CRITICAL' => 'OLT_ALARMAS_CRITICAL', 'MAJOR' => 'OLT_ALARMAS_MAJOR',
                 'MINOR' => 'OLT_ALARMAS_MINOR', 'WARNING' => 'OLT_ALARMAS_WARNING'];
      foreach ($tablas as $tabla) $db->query("DELETE FROM $tabla");
      $db->query('DELETE FROM OLT_CANTIDAD_ALARMAS_DETALLE');

      foreach ($tablas as $sev => $tabla) {
          insertar_lote($db, $tabla, '(equipo,ip,puerta,alarma,fecha,fecha_proceso)', $filas[$sev]);
      }
      insertar_lote($db, 'OLT_CANTIDAD_ALARMAS_DETALLE',
          '(equipo,ip,region,cantidad_critical,cantidad_major,cantidad_minor,cantidad_warning,fecha)',
          $cantidades);

      $db->commit();
      $cargado = true;
  } catch (Throwable $e) {
      $db->rollback();                   // quedan los datos de la hora anterior
      echo "Error en la carga: " . $e->getMessage() . "\n";
  } finally {
      $db->close();
  }
  ```
  > Con PHP 8.1+ mysqli lanza excepciones por defecto. En 8.0, agregar `mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);` al inicio para que el `catch` funcione.
- [ ] **2.13** Si la carga fue bien, borrar la carpeta del lote; si falló, dejarla para revisar:

